# Cloumy — 프로젝트 개요

> ⚠️ **2026-07-06 타겟 전환**: 한국인 국내 여행자 → **방한 외국인 관광객(미국·일본·중국·대만)**. 이 문서는 Notion 기획 문서(서비스 개요/타겟 페르소나/MVP 범위/로드맵&KPI) 기준으로 갱신됨. 배경은 `planning/strategy.md`, `planning/milestones.md`의 "Phase 2.5: 타겟 전환" 참고.

## 한 줄 소개
방한 외국인 관광객이 언어·정보 장벽 없이 한국을 깊이 경험할 수 있도록, AI가 루트를 짜고 여행 중 실시간으로 돕는 **올인원 여행 실행 앱**

## 문제와 시장 규모

**3가지 핵심 페인포인트:**
1. **언어 장벽** — 한국어 정보 장벽으로 현지 진짜 정보 접근 불가. 번역기 반복 사용
2. **여행 중 이탈 대응 불가** — 웨이팅·날씨·돌발 상황 시 실시간 대응 앱 전무
3. **목적형·K-culture 정보 공백** — K-pop 성지, K-drama 촬영지, 콘서트 등 테마 특화 루트 정보 부재

**시장 규모 (2026 기준):**
| 구분 | 수치 | 출처 |
|------|------|------|
| 연간 방한 외국인 | 약 1,600만 명 | KTO |
| K-content 동기 방한 비율 | 41.8% (2026 Q1) | 한국관광공사 |
| 방한 외국인 중 30세 이하 | 35.6% | 코리아넷 |
| 일본 방한 (2026 Q1) | 94만 명 (+20% YoY) | KTO |
| 중국 방한 (2026 Q1) | 145만 명 (+29% YoY) | KTO |
| Trip Pass 전환율 목표 | 5% (업계 평균 2.6%) | RevenueCat 2026 |
| Phase 1 목표 MRR | $870(보수)~$3,000(목표) | Cloumy 내부 추정 |

**직접 경쟁사**: GOKO (2026.06.26 출시, iOS 전용, 무료, 루트 생성만 — 실행 단계 없음). 상세 비교는 `planning/strategy.md` 참고.

## MVP 범위 (Phase 1, 0~6개월)

### 포함 — MVP 10가지 기능 (현재 14개 도시 구현됨: 서울·부산·제주·경주·강릉·전주·여수·인천·대전·대구·광주·속초·춘천·거제)
1. **AI 루트 자동 생성 + 지도 기반 시각화** ← 앱 핵심 가치 (구현 완료)
2. **Pin & Reshuffle** — 마음에 드는 일정 고정, 싫은 슬롯만 재추천 (구현 완료)
3. **다국어 AI 챗봇 (텍스트 + 카메라)** — 텍스트는 다국어 응답 구현 완료, 카메라 입력(메뉴판·키오스크 번역)은 계획
4. **여행자 취향 태그 시스템 (10종)** — 현재 한국어 해시태그 방식 → K-pop Pilgrim 등 Notion 10종 영어 태그로 재설계 계획
5. **루트 공유 + Hidden Gems (자동 번역)** — 둘 다 미구현, Hidden Gems는 자금 확보 후 진행
6. **콘서트·이벤트 앵커 (Serper 실시간 검색 + KOPIS)** — 계획, 미구현
7. **Foreigner Friendly Score** — 계획, 미구현 (`places` 테이블에 관련 컬럼 없음)
8. **예산 관리 & 지출 추적** (구현 완료, 다국어·다통화 대응은 후속)
9. **지도 내비 모드** — 현재 Google Maps 딥링크만 있음. 지하철·버스→Naver / 도보→Google / 택시→카카오T 3-way 분기로 확장 계획
10. **그룹 여행 모드** — 예산 추적 검증 후 MVP 후반부 추가, 미구현

### 제외 — Phase 2 이후
투어·숙박 예약 연동(Klook·Viator), 일본어·중국어 UI 전면 지원(영어 우선 출시), 리뷰 문화 해석 자동화, 행동 기반 태그 자동 보정, AI 여행 일지 자동 생성, 더치페이 정산, 인앱 지도 내비 완전 구현, 음성 챗봇

```

  · Standard $4.99 / Extended $7.99
        ↓
[Layer 2 — 예약 수수료]  Phase 2 — 숙박 5~8%, 투어·티켓 8~12%
        ↓
[Layer 3 — B2B]  Phase 3 — 지자체·관광청 데이터 리포트, 익명화 여행 패턴, K-culture 브랜드 네이티브 광고
```

**목표**: Trip Pass 전환율 5% (업계 평균 2.6% 상회), Phase 1 목표 MRR $3,000+.

## KPI & North Star Metric

**North Star Metric**: 여행 기간 중 루트를 실제로 사용해 완료한 Trip Pass 유저 수 — 단순 다운로드·루트 생성 수가 아닌 "돈 내고 → 여행 중 앱 써서 → 루트 완주"까지 도달한 유저 수.

| 단계 | MAU | 루트 생성(누적) | Trip Pass 전환율 | 여행기간 내 DAU율 | MRR |
|------|-----|-----------|-----------|------------|---------|
| Phase 1 (6개월) | 3,000명 | 10,000개 | ≥ 3% | ≥ 60% | $3,000+ |
| Phase 2 (18개월) | 20,000명 | - | ≥ 5% | ≥ 70% | $15,000+ |
| Phase 3 (36개월) | 100,000명 | - | - | - | $100,000+ |

상세 KPI 체계(참여·비즈니스·데이터 품질)는 `planning/priorities.md`, Notion "6. 로드맵 & KPI" 참고.

## 개발 시작 순서 (권장)

```
Pre-launch (출시 -3개월): 베타 헌터 300명 모집 → Hidden Gems 시드 데이터 500~1,000개 확보
Week 1~2:   환경 설정 — 프로젝트 초기화, DB 설정, CI/CD
Week 3~6:   데이터 파이프라인 — TourAPI/KOPIS/카카오 로컬 수집 + pgvector 임베딩
Week 5~10:  AI 루트 생성 — FastAPI + RAG + OR-Tools TSP + 지도 시각화
Week 7~8:   Pin & Reshuffle — 루트 생성 연장선
Week 9~12:  AI 챗봇 — Function Calling + 멀티턴 + Redis 세션
Week 11~14: 예산 관리 + Hidden Gems + 내비 딥링크
Week 15~16: 결제 연동 + 통합 테스트
Week 17~18: 그룹 여행 모드 + 오프라인 저장 (Phase 1 후반)
```

> 📌 AI 기능(루트 생성 + 챗봇)이 전체 개발 기간의 약 50% 차지. 이 두 기능이 완성되지 않으면 MVP 자체가 성립하지 않으므로 최우선 진행.
