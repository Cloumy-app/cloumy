# Cloumy — 프로젝트 개요

## 한 줄 소개
목적지와 날짜만 넣으면 AI가 나만의 루트를 짜주고, 여행 중에도 챗봇이 함께하며, 다녀온 사람들의 실제 루트까지 참고할 수 있는 **여행 원스톱 앱**

## 핵심 가치 제안

| 페르소나 | 기존의 경험 | Cloumy 사용 후 |
|----------|-------------|----------------|
| 계획 울렁증 직장인 | 4.2개 앱 전전, 수시간 소요 | 3분 입력 → AI가 완성된 일정 제공 |
| 먹방 원정대 | 맛집 리스트 따로, 동선 따로 | 먹방 태그 기반 최적 루트 자동 생성 |
| 콘서트 원정 | 공연 시간 맞춰 수동 조합 | 공연 시간 입력 → AI가 전체 동선 배치 |
| 여행 중 돌발 상황 | 혼자 구글·카카오 전전 | 챗봇에게 물어보면 즉시 대안 제시 |
| 여행 마니아 | 이미 가본 곳만 추천 → 식상 | 방문 이력 기반 숨은 명소만 추천 |

## 문제와 시장 규모

**3가지 핵심 페인포인트:**
1. **계획 장벽** — 여행 준비 시 평균 4.2개 채널 사용 (트리플 리서치). 내 날짜·예산·스타일에 맞는 루트는 없다
2. **여행 중 이탈** — 날씨·웨이팅·돌발 상황 시 실시간 대응 앱 전무. 트리플·야놀자 모두 사전 계획 도구에 한정
3. **목적형 정보 부재** — 먹방·콘서트·신혼 등 목적 특화 루트는 어디에도 없다

**시장 규모:**
| 구분 | 규모 | 출처 |
|------|------|------|
| TAM | 약 14조 원 | 한국 온라인 여행 시장 (IMARC Group, 2024) |
| SAM | 약 4.2조 원 | AI 계획형 플래닝 세그먼트 (온라인 여행 × 30%) |
| SOM (3년) | 50~100억 원 | MAU 20만 × 결제 전환율 30% × 5,500원 × 2.5회/년 |
| 한국 CAGR | 연 9.86% | IMARC Group (2025~2033) |
| AI 여행 시장 | 36억 달러 (CAGR 22.34%) | SNS Insider, 2024 |
| 한국 AI 활용률 | 약 20% (글로벌 40% 대비 성장 여지 큼) | ResearchAndMarkets, 2024 |

## MVP 범위 (Phase 1, 0~6개월)

### 포함 — MVP 7가지 기능 (국내 주요 도시 20개)
1. **AI 루트 자동 생성 + 지도 기반 시각화** ← 앱 핵심 가치
2. **Pin & Reshuffle** — 마음에 드는 일정 고정, 싫은 슬롯만 재추천
3. **AI 챗봇** — 여행 전 대화형 플래닝 + 여행 중 실시간 어시스턴트
4. **예산 관리 & 지출 추적** (개인) — 계획/비계획 지출 분리
5. **Hidden Gems + 태그 커뮤니티** — UGC 장소 등록 + 루트 연동
6. **지도 내비 모드** — 카카오맵 딥링크 (MVP), 인앱 내비 (Phase 2)
7. **그룹 여행 모드** — 개인 지출 추적 검증 후 MVP 후반부 추가

### Phase 1 후반 추가 (M5~6)
- **오프라인 저장** — 해외여행 1위 앱 목표로 Phase 2 예정에서 당김

### 제외 — Phase 2 이후
- 국내/해외 예약 연동, AI 여행 일지 자동 생성, 더치페이 정산
- 챗봇 통합 번역, 이미지 기반 Vibe Search, 영수증 OCR
- 인앱 지도 내비 완전 구현, 음성 챗봇, AR 포토스팟

## 기술 스택 요약

## 비즈니스 모델 (3개 레이어)

```
[Layer 1 — 트립 패스]  여행을 갈 때만 내는 직접 결제
  · 당일치기 1,900원 / 3박 이하 4,900원 / 4박 이상 7,900원
  · 한국인 평균 연 2.47회 여행 → 연간 지출 약 13,750원 (월 구독 환산 1,100원)
        ↓
[Layer 2 — 예약 수수료]  Phase 2 — 숙박 5~8%, 투어·티켓 8~12%
        ↓
[Layer 3 — B2B]  Phase 2 — 지자체·관광청 데이터 리포트, 익명화 여행 패턴
```

**Unit Economics 목표:**
- 여행당 결제 전환율: 30%
- 평균 결제 단가(ARPPU): 5,500원
- 연간 결제 횟수: 2.5회
- 유저 연간 매출 기여: **13,750원**
- LTV/CAC: **2.75x 이상** (예약 수수료 제외)

## 개발 시작 순서 (권장)

```
Pre-launch (출시 -3개월): 베타 헌터 300명 모집 → Hidden Gems 시드 데이터 500~1,000개 확보
Week 1~2:   환경 설정 — 프로젝트 초기화, DB 설정, CI/CD
Week 3~6:   데이터 파이프라인 — TourAPI/KOPIS/카카오 로컬 수집 + pgvector 임베딩
Week 5~10:  AI 루트 생성 — FastAPI + RAG + OR-Tools TSP + 지도 시각화
Week 7~8:   Pin & Reshuffle — 루트 생성 연장선
Week 9~12:  AI 챗봇 — Function Calling + 멀티턴 + Redis 세션
Week 11~14: 예산 관리 + Hidden Gems + 내비 딥링크
Week 15~16: 결제 연동 + 통합 테스트
Week 17~18: 그룹 여행 모드 + 오프라인 저장 (Phase 1 후반)
```

> 📌 AI 기능(루트 생성 + 챗봇)이 전체 개발 기간의 약 50% 차지. 이 두 기능이 완성되지 않으면 MVP 자체가 성립하지 않으므로 최우선 진행.
