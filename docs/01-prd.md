# PRD: Cloumy

## 문제 정의
한국인은 연 평균 2.47회 여행을 가며, 매번 4.2개의 앱·채널을 돌아다니며 직접 계획을 짠다. 여행 중 일정이 틀어져도 실시간 대응해주는 앱은 없고, 먹방·콘서트·신혼처럼 목적형 특화 정보는 어디서도 찾기 어렵다. Cloumy는 AI가 이 모든 과정을 하나의 앱에서 끝낸다.

## 사용자 스토리

### 페르소나 A — 계획 울렁증 직장인 (메인 타겟)
- 바쁜 직장인으로서, 여행지·날짜·인원·태그만 입력하면 AI가 최적 루트를 생성해주기를 원한다. 왜냐하면 직접 동선을 짜는 데 2~3시간이 걸리기 때문이다.
- 여행자로서, 마음에 드는 일정은 고정하고 맘에 안 드는 슬롯만 다시 추천받고 싶다. 왜냐하면 AI 추천이 100% 마음에 들지 않아도 전체를 다시 짜기는 싫기 때문이다.

### 페르소나 B — 먹방 원정대
- 먹방 여행자로서, 맛집 태그를 선택하면 AI가 이동 동선 최적화된 먹방 루트를 자동 생성해주기를 원한다. 왜냐하면 맛집 리스트와 동선을 따로 조합하는 게 너무 번거롭기 때문이다.
- 루트 크리에이터로서, 내가 발굴한 맛집 루트를 커뮤니티에 공유하고 얼마나 사람들에게 도움이 됐는지 피드백을 받고 싶다.

### 페르소나 C — 콘서트 원정
- 공연 원정 여행자로서, 콘서트 시간을 입력하면 AI가 공연 전후 숙소·식사·이동을 자동 배치해주기를 원한다. 왜냐하면 공연 시간에 맞춰 수동으로 조합하는 게 복잡하기 때문이다.

### 페르소나 E — 해외 자유여행자
- 여행자로서, 여행 중 "지금 근처 카페 추천해줘"를 앱에 물어보면 바로 답해주기를 원한다. 왜냐하면 구글에 검색하고 지도로 넘어가는 과정이 번거롭기 때문이다.
- 여행자로서, 챗봇에게 "기념품 12,000원 썼어"라고 말하면 지출이 자동으로 기록되기를 원한다.

### 페르소나 F — 여행 마니아 (핵심 UGC 생산자)
- 여행 마니아로서, 방문 이력에 기반해 "내가 아직 안 가본" 숨은 명소만 추천받고 싶다. 왜냐하면 기존 앱은 항상 유명 관광지만 추천하기 때문이다.
- 여행 마니아로서, 내가 발견한 Hidden Gem을 등록하고 다른 사람의 루트에 반영되는 것을 보며 뿌듯함을 느끼고 싶다.

## 기능 명세

### P0 — MVP 필수 (없으면 출시 불가)

#### 1. 인증
- 카카오 소셜 로그인 (국내 사용자 주력)
- 구글 소셜 로그인 (해외 대비)
- 애플 Sign In (iOS 앱스토어 정책 필수)
- JWT Access/Refresh Token 발급 및 갱신

#### 2. AI 루트 생성 + 지도 시각화
- Step 1~3 입력 플로우: 목적지 → 날짜/인원 → 여행 스타일·예산·앵커 장소
- LLM + RAG 기반 루트 생성 (앵커 장소 고정, 나머지 최적 배치)
- 지도 전체 보기: Day별 색상 구분 경로선, 방문 순서 번호 핀
- Day 탭 뷰: 해당 날 동선 + 이동 시간/수단
- 타임라인 뷰: 하단 슬라이드업, 지도와 실시간 연동
- 응답 속도: 첫 생성 5~10초 (스트리밍), 캐시 히트 1초 이내
- 환각 방지: RAG로 실제 DB 장소만 사용, LLM 출력 후 place_id 재검증
- **국내 커버리지: 주요 도시 20개 (MVP 기준)**

#### 3. Pin & Reshuffle
- 📌 고정: 해당 슬롯 유지
- 🔄 재추천: 해당 슬롯만 재생성 → 대안 3개 슬라이드 표시
- ❌ 제거: 빈 슬롯 AI 자동 채우기
- 조작 시 지도 경로 실시간 업데이트
- 응답 속도: 2~3초 (Haiku 모델)

#### 4. AI 챗봇 (여행 전·중)
- 여행 전: 대화형 루트 생성 (Step 1~3 플로우 대안)
- 여행 중: 현위치 기반 장소 추천, 대안 제안, 지출 자동 기록
  - "지금 근처 카페 추천" → 현위치 기반 카카오 로컬 검색
  - "웨이팅 너무 길어" → 반경 500m 대안 즉시 제안
  - "내일 비 온다는데 실내로" → 기상청 API 연동 루트 대체
  - "기념품 12,000원 썼어" → 비계획 지출 자동 분류·기록
- 챗봇 응답 스트리밍 (WebSocket)
- 멀티턴 컨텍스트 유지 (Redis 세션)
- 단순 질문: Haiku 4.5 / 복잡 플래닝·루트 수정: Sonnet 4.6

#### 5. 예산 관리 & 지출 추적 (개인)
- 총예산 입력 → AI 카테고리별 자동 배분 (숙박 35%, 식음료 30%, 교통 20%, 입장료 10%, 기타 5%)
- 여행 목적 태그에 따른 비율 자동 조정 (#먹방 → 식음료 +10%)
- 슬라이더로 비율 직접 조정
- 계획 지출: 원탭 "완료" 체크 / 금액 수정
- 비계획 지출: + 버튼 또는 챗봇 자연어 입력
- 예산 초과 시: 잔여 예산 배너 + 챗봇 저가 대안 제안
- 여행 후 지출 리포트 (계획 vs 비계획, 카테고리별 분석)

#### 6. 지도 내비 모드 (카카오맵 딥링크)
- "다음 장소로 이동" → 카카오맵 딥링크 자동 호출 (목적지 좌표 전달)
- Cloumy 앱 복귀 시 현재 일정 위치 유지

#### 7. 트립 패스 결제
- 영구 무료: 지도 탐색·북마크, AI 루트 미리보기 (저장 불가)
- 첫 여행 무료 체험 (신규 가입 자동 지급)
- 당일치기 1,900원 / 3박 이하 4,900원 / 4박 이상 7,900원
- 토스페이먼츠 웹뷰 결제 (인앱결제 30% 수수료 우회)
- 환불: 여행 시작 전 전액 환불 / 시작 후 불가

### P1 — 초기 출시 후 빠르게 추가

#### Hidden Gems + 태그 커뮤니티
- 장소 등록: 사진 + GPS 인증 (현장 **반경 100m** 이내 → 집에서 등록 원천 차단)
- 희소성 점수 80+ 시 🔮 Hidden Gem 배지 자동 부여
- 태그 체계: 목적 태그(#먹방 #카페 등) + 분위기 태그(#현지인픽 #조용한 등)
- 루트 생성 Step 3에서 Hidden Gems 토글 ON → 루트에 우선 반영 (최대 30%)
- 레벨 시스템: 탐험가 → 로컬가이드 → 레전드
- **베타 헌터 사전 시드 전략**: 출시 -3개월부터 300명 모집, 도시별 집중 등록, 목표 500~1,000개 확보
- AI가 이미 유명한 관광지는 Hidden Gem 등록 자동 차단

#### 그룹 여행 모드
- 여행방 생성 + 친구 초대 (링크/QR)
- 일정 슬롯별 좋아요/싫어요 투표
- 실시간 동기화 (WebSocket + Redis Pub/Sub)
- 개인별 지출 추적 (합산·더치페이는 Phase 2)
- **선행 조건**: 개인 지출 추적(P0) 검증 완료 후 추가

#### 오프라인 저장 ← Phase 2 예정에서 Phase 1 후반으로 당김
- 해외여행 1위 앱 목표로 MVP 후반 추가
- 루트 + 지도 타일 오프라인 저장 (4박 이상 패스 포함)

#### KOPIS 공연 데이터 연동
- 공연예술통합전산망 (KOPIS) Open API — 전국 공연·뮤지컬·클래식·콘서트 일정
- 콘서트 원정(페르소나 C) 핵심 기능
- 루트 생성 시 공연 시간 앵커로 자동 배치

#### FCM 푸시 알림
- 예산 초과 알림
- Hidden Gems 핫플 경보 (희소성 50 미만)
- 여행 당일 일정 시작 알림

### P2 — 나중에 (Phase 2~3)

- 국내 예약 연동 (야놀자, 마이리얼트립) — 제휴 파트너십 선행 필수
- 해외 예약 연동 (Kiwi.com MCP, Trivago MCP) — 해외 확장 타이밍
- AI 여행 일지 자동 생성 + SNS 공유 (바이럴 엔진)
- 더치페이 정산
- 챗봇 통합 번역 (일본어·영어 — Phase 2 해외 확장 시)
- 인앱 지도 내비 완전 구현 (Google Maps Navigation SDK)
- 이미지 기반 Vibe Search
- 포인트 & 리워드 / 크리에이터 수익 분배
- Stripe 해외 결제
- 실시간 환율 API 연동
- 음성 챗봇 (STT)
- AR 포토스팟
- 상표 출원 완료 ("Cloumy"/"Cloumy") + 마드리드 국제상표 출원

| 항목 | 기준 |
|------|------|
| AI 루트 첫 생성 | 10초 이내 (스트리밍으로 체감 단축) |
| Pin & Reshuffle | 3초 이내 |
| 챗봇 응답 | 2초 이내 (Haiku), 5초 이내 (Sonnet) |
| 가용성 | 99% (MVP 수준) |

| D7 리텐션 | 30% (MVP KPI) |

## 범위 외 (Scope Out)
- **팀 협업 기능 (B2B SaaS)**: 그룹 모드와 다름, 완전 제외
- **AI가 숙소·항공 직접 예약**: Phase 2~3 제휴 후
- **리뷰/평점 자체 구축**: 카카오/네이버 리뷰 수 활용으로 대체
- **국내 화폐 외 환율 연동**: Phase 2 해외 확장 시
