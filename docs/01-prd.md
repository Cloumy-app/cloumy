# PRD: Cloumy

> ⚠️ **2026-07-06 타겟 전환**: 한국인 국내 여행자 → 방한 외국인 관광객(미국·일본·중국·대만). 아래 페르소나·기능 명세는 Notion 기획 문서 기준으로 갱신됨.

## 문제 정의
방한 외국인 관광객은 언어 장벽 때문에 현지 진짜 정보에 접근하지 못하고, 대부분의 정보를 번역기로 억지로 해독한다. 여행 중 일정이 틀어져도(웨이팅·날씨·돌발 상황) 실시간 대응해주는 앱은 없고, K-pop 성지·K-drama 촬영지·콘서트 같은 K-culture 목적형 특화 정보는 어디서도 찾기 어렵다. Cloumy는 AI가 이 모든 과정을 하나의 앱, 그것도 관광객의 모국어로 끝낸다.

## 사용자 스토리

### 페르소나 A — 미국 K-pop 팬 Sarah (메인 타겟)
- 첫 방한 여행자로서, 여행지·날짜·인원·취향 태그만 입력하면 AI가 최적 루트를 생성해주기를 원한다. 왜냐하면 K-pop 성지는 정했지만 나머지 일정을 어떻게 채울지 모르기 때문이다.
- 여행자로서, 마음에 드는 일정은 고정하고 맘에 안 드는 슬롯만 다시 추천받고 싶다. 왜냐하면 AI 추천이 100% 마음에 들지 않아도 전체를 다시 짜기는 싫기 때문이다.

### 페르소나 B — 일본 재방문자 Yui
- 연 2~3회 재방문하는 여행자로서, 방문 이력에 기반해 "내가 아직 안 가본" 숨은 명소만 추천받고 싶다. 왜냐하면 기존 앱은 항상 유명 관광지만 추천하기 때문이다.
- 여행자로서, 한국어 리뷰를 자동으로 해석해서 보여주기를 원한다. 왜냐하면 네이버 지도는 쓸 줄 알지만 한국어 리뷰 해독은 여전히 어렵기 때문이다.

### 페르소나 C — 중국 자유여행자 Wei
- 여행자로서, 중국어로 챗봇에 질문하면 즉시 답해주기를 원한다. 왜냐하면 결제 방법·교통카드·식당 예약 같은 기본 정보에서 계속 막히기 때문이다.
- 여행자로서, 카드 결제 가능한 식당을 필터링해서 보고 싶다 (Foreigner Friendly Score).

### 페르소나 D — 대만 K-culture 팬 Mei
- 여행자로서, K-beauty·K-food·K-pop 복합 테마 태그를 선택하면 AI가 효율적인 동선으로 통합해주기를 원한다. 왜냐하면 여러 목적지를 각자 찾다 보면 동선이 엉키기 때문이다.
- 여행자로서, 번체 중국어로 전체 안내를 받고 싶다.

### 세컨더리 — K-pop 콘서트 투어리스트
- 공연 원정 여행자로서, 콘서트 시간을 입력하면 AI가 공연 전후 숙소·식사·이동을 자동 배치해주기를 원한다. 왜냐하면 공연 후 빈 시간을 어떻게 채울지 막막하기 때문이다.

### 공통 — 여행 중 돌발 상황
- 여행자로서, 여행 중 "웨이팅 2시간인데 근처에 뭐 있어?"를 모국어로 앱에 물어보면 바로 답해주기를 원한다. 왜냐하면 번역기로 검색하고 지도로 넘어가는 과정이 번거롭기 때문이다.
- 여행자로서, 챗봇에게 "₩15,000 썼어"라고 말하면 지출이 자동으로 기록되기를 원한다.
- 여행자로서, 메뉴판이나 키오스크 화면을 사진으로 찍으면 챗봇이 번역·설명해주기를 원한다 (계획, 미구현).

## 기능 명세

### P0 — MVP 필수 (없으면 출시 불가)

#### 1. 인증
- 구글 소셜 로그인 (외국인 관광객 주력)
- 애플 Sign In (iOS 앱스토어 정책 필수)
- ⚠️ 카카오 소셜 로그인은 국내 전용 서비스라 외국인 타겟과 안 맞아 보류 (재검토 필요)
- JWT Access/Refresh Token 발급 및 갱신

#### 2. AI 루트 생성 + 지도 시각화
- Step 1~3 입력 플로우: 목적지 → 날짜/인원 → 여행 스타일·예산·앵커 장소
- LLM + RAG 기반 루트 생성 (앵커 장소 고정, 나머지 최적 배치)
- 지도 전체 보기: Day별 색상 구분 경로선, 방문 순서 번호 핀
- Day 탭 뷰: 해당 날 동선 + 이동 시간/수단
- 타임라인 뷰: 하단 슬라이드업, 지도와 실시간 연동
- 응답 속도: 첫 생성 5~10초 (스트리밍), 캐시 히트 1초 이내
- 환각 방지: RAG로 실제 DB 장소만 사용, LLM 출력 후 place_id 재검증
- **커버리지: 현재 14개 도시 구현됨 (서울·부산·제주·경주·강릉·전주·여수·인천·대전·대구·광주·속초·춘천·거제) — Notion MVP 목표 5개 도시를 이미 초과 달성**

#### 3. Pin & Reshuffle
- 📌 고정: 해당 슬롯 유지
- 🔄 재추천: 해당 슬롯만 재생성 → 대안 3개 슬라이드 표시
- ❌ 제거: 빈 슬롯 AI 자동 채우기
- 조작 시 지도 경로 실시간 업데이트
- 응답 속도: 2~3초 (Haiku 모델)

#### 4. 다국어 AI 챗봇 (여행 전·중, 텍스트 + 카메라)
- 다국어 응답: 사용자 메시지 언어(영어/일본어/중국어)로 자동 응답 — **구현 완료 (2026-07-06)**
- 여행 전: 대화형 루트 생성 (Step 1~3 플로우 대안) — 계획, 미구현
- 여행 중: 현위치 기반 장소 추천, 대안 제안, 지출 자동 기록 — 읽기전용 도구 3종(`search_nearby_places`/`get_weather_forecast`/`get_route_status`) 구현 완료
  - "Waiting is too long here" → 반경 500m 대안 즉시 제안
  - "It's raining tomorrow" → 날씨 API 연동 루트 대체
  - "I spent ₩15,000 on souvenirs" → 비계획 지출 자동 분류·기록 (예산 기능 선행 필요, 계획)
- **카메라 입력 (계획, 미구현)**: KOIN K-amera 벤치마킹. 메뉴판 사진 → 번역+추천, 키오스크 사진 → 단계별 안내, 간판 사진 → 즉시 번역
- 멀티턴 컨텍스트 유지 (Redis 세션, TTL 2h) — 구현 완료
- 단순 질문: Haiku 4.5 / 복잡 플래닝·루트 수정: Sonnet 4.6
- 스트리밍은 계획 단계 (현재 non-streaming 단발 응답)

#### 5. 예산 관리 & 지출 추적 (개인)
- 총예산 입력 → AI 카테고리별 자동 배분 (숙박 35%, 식음료 30%, 교통 20%, 입장료 10%, 기타 5%)
- 여행 목적 태그에 따른 비율 자동 조정 (#먹방 → 식음료 +10%)
- 슬라이더로 비율 직접 조정
- 계획 지출: 원탭 "완료" 체크 / 금액 수정
- 비계획 지출: + 버튼 또는 챗봇 자연어 입력
- 예산 초과 시: 잔여 예산 배너 + 챗봇 저가 대안 제안
- 여행 후 지출 리포트 (계획 vs 비계획, 카테고리별 분석)

#### 6. 지도 내비 모드 (3-way 딥링크 분기 — 현재는 Google만 구현)
- "다음 장소로 이동" 탭 → 이동 수단별 딥링크 분기:
  - 지하철·버스 → **Naver Maps** (한국 대중교통 정확도 최우선, 영어 모드 지원) — 계획, 미구현
  - 도보 → **Google Maps** (외국인에게 가장 익숙) — 구현 완료
  - 택시 → **카카오T** (해외 카드 결제 가능) — 계획, 미구현
- 앱 미설치 시 웹 fallback (map.naver.com / maps.google.com)
- Cloumy 앱 복귀 시 현재 일정 위치 유지

#### 7. 트립 패스 결제
- 영구 무료: 지도 탐색·북마크, AI 루트 미리보기 (저장 불가)
- 첫 여행 무료 체험 (신규 가입 자동 지급)
- Standard $4.99 / Extended $7.99
- ⚠️ 결제 수단 미확정: 토스페이먼츠는 국내 전용 PG라 외국인 해외 카드 결제 미지원. Stripe 등 국제결제 PG 검토 필요 (별도 논의, 아직 결제 기능 자체가 미구현)
- 환불: 여행 시작 전 전액 환불 / 시작 후 불가

### P1 — 초기 출시 후 빠르게 추가

#### Hidden Gems + 태그 커뮤니티
- 장소 등록: 사진 + GPS 인증 (현장 **반경 100m** 이내 → 집에서 등록 원천 차단)
- 희소성 점수 80+ 시 🔮 Hidden Gem 배지 자동 부여
- 태그 체계: 목적 태그(#먹방 #카페 등) + 분위기 태그(#현지인픽 #조용한 등)
- 루트 생성 Step 3에서 Hidden Gems 토글 ON → 루트에 우선 반영 (최대 30%)
- 레벨 시스템: 탐험가 → 로컬가이드 → 레전드
- **베타 헌터 사전 시드 전략**: 출시 -3개월부터 300명 모집, 도시별 집중 등록, 목표 500~1,000개 확보
- AI가 이미 유명한 관광지는 Hidden Gem 등록 자동 차단

#### 그룹 여행 모드
- 여행방 생성 + 친구 초대 (링크/QR)
- 일정 슬롯별 좋아요/싫어요 투표
- 실시간 동기화 (WebSocket + Redis Pub/Sub)
- 개인별 지출 추적 (합산·더치페이는 Phase 2)
- **선행 조건**: 개인 지출 추적(P0) 검증 완료 후 추가

#### 오프라인 저장 ← Phase 2 예정에서 Phase 1 후반으로 당김
- Extended 패스 전용 기능으로 MVP 후반 추가
- 루트 + 지도 타일 오프라인 저장

#### 콘서트·이벤트 앵커 (Serper API + KOPIS)
- 유저 검색 → pgvector DB 조회(TTL 7일) → 없으면 Serper 실시간 웹 검색 → LLM 구조화 추출 → DB 캐시
- 클래식·뮤지컬·연극은 KOPIS(공연예술통합전산망) 우선, K-pop·팝업은 Serper 특화
- K-pop 콘서트 투어리스트 페르소나 핵심 기능
- 루트 생성 시 공연 시간 앵커로 자동 배치, 공연 전후 근처 식사·귀숙 경로 자동 배치

#### Foreigner Friendly Score
- 5개 항목: English menu / Card payment / English kiosk / Spice level / Dietary info(Vegan·Halal·Gluten-free)
- Phase 1: 서울·부산 주요 관광지 200곳 수동 입력, 이후 유저 신고·수정 크라우드소싱
- `places` 테이블에 관련 컬럼이 없어 스키마 설계 선행 필요

#### 여행자 취향 태그 시스템 재설계 (10종)
- 현재 `#관광`·`#야경` 등 한국어 해시태그 방식 → K-pop Pilgrim, K-drama Fan, K-food Lover, K-beauty Addict, Culture Explorer, Nature Seeker, Shopping Maven, Content Creator, Night Owl, Cafe Hopper 10종으로 재설계
- 온보딩 스와이프 UI(8장 이미지 카드)로 초기 태그 2~3개 자동 부여
- Discovery 피드 필터링 + 루트 생성 Step에서 자동 pre-select에 활용

#### FCM 푸시 알림
- 예산 초과 알림
- Hidden Gems 핫플 경보 (희소성 50 미만)
- 여행 당일 일정 시작 알림

### P2 — 나중에 (Phase 2~3)

- 투어·숙박 예약 연동 (Klook·Viator) — 제휴 파트너십 선행 필수 (셀프서비스 API 아님)
- AI 여행 일지 자동 생성 + SNS 공유 (바이럴 엔진)
- 더치페이 정산
- 인앱 지도 내비 완전 구현 (Google Maps Navigation SDK)
- 장소 데이터 영문화 (`places.name`/`address` 번역 — 배치/실시간 방식 논의 필요)
- 행동 기반 태그 자동 보정 (이벤트 로깅 데이터 축적 후)
- 이미지 기반 Vibe Search
- 포인트 & 리워드 / 크리에이터 수익 분배
- 음성 챗봇 (STT)
- AR 포토스팟
- 상표 출원 완료 ("Cloumy") + 마드리드 국제상표 출원

> ⚠️ 기존에 있던 "국내 예약 연동(야놀자·마이리얼트립)", "해외 예약 연동(Kiwi.com·Trivago)", "챗봇 통합 번역(Phase2 해외 확장 시)", "Stripe 해외 결제", "실시간 환율 API(해외 확장 시)"는 한국인이 해외로 나가는(아웃바운드) 시나리오 전제였던 항목 — 이번 타겟 전환(외국인이 한국에 오는 인바운드)과 맞지 않아 제거·대체. 챗봇 다국어 번역은 이미 완료됐고, 국제결제(PG 미확정)는 P0 "트립 패스 결제" 항목에 이미 반영됨.
