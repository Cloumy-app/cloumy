# Cloumy 제품·비즈니스 전략

> 이 문서는 제품 방향과 비즈니스 결정의 단일 진실 공급원(Single Source of Truth)이다.
> 기술 상세는 `feature-*.md`, 구현 계획은 `milestones.md`, 우선순위는 `priorities.md` 참고.

---

## 핵심 비전

**"AI가 완성된 여행 루트를 짜주고, 여행 중에도 함께한다."**

사용자가 목적지·날짜·스타일만 입력하면 AI가 최적 동선·예산·팁이 담긴 완성 루트를 생성하고,
여행 중에는 챗봇이 실시간으로 대안 추천·예산 추적·현지 정보를 제공한다.

장기적으로는 현지 큐레이터를 직접 파견해 API 데이터가 아닌 검증된 현지 장소 데이터로
경쟁 우위를 확보한다.

---

## 경쟁 포지셔닝

### vs 트리플 (핵심 경쟁자)

| | 트리플 | Cloumy |
|--|--------|--------|
| AI 역할 | 스타일 기반 장소 목록 제안 | 완성된 시간표 + 최적 동선 생성 |
| 동선 최적화 | 없음 (수동 정렬) | OR-Tools TSP + 실제 이동 시간 |
| 여행 중 AI | 없음 | 챗봇 (대안 추천·예산 추적·현지 정보) |
| 콘텐츠 | 방대한 에디터 큐레이션 + UGC | TourAPI + 카카오 + 트렌딩 데이터 |
| 예약 | 항공·호텔 통합 | MVP 없음 |

**포지셔닝**: 트리플 = "스스로 계획하는 사람의 도구", Cloumy = "AI한테 맡기고 싶은 사람의 도구"

**국내 1차 경쟁자**: 트리플보다 **네이버 블로그 검색** — 이걸 이기는 것이 1차 목표.

## 단계별 로드맵

### Phase 1 — 국내 MVP (현재)

**목적**: 제품 검증 + AI 품질 튜닝 런웨이. 국내 수익화가 목표가 아님.

- **지역**: 소도시 5개 (제주·부산·경주·강릉·전주) → 베타 전 국내 20개 도시
- **타겟**: 처음 가는 소도시 여행자, 커플, 계획 귀찮아하는 20~30대
- **데이터**: TourAPI + 카카오 배치 (무료), 네이버 블로그 트렌딩 (무료)
- **성공 지표**: MAU보다 **재사용률 + 트립 패스 전환율** 우선

국내에서 이길 수 있는 모멘트:
1. 처음 가는 지역 + 시간·예산 제약 → 30~60분 리서치를 3분으로
2. 여행 중 실시간 변경 → "웨이팅 1시간, 대안 추천해줘" (트리플 불가)
3. 그룹 여행 취향 조율 → AI가 밸런스 잡힌 루트 하나로 해결

바이럴 루프: 루트 결과를 SNS 카드로 공유 → 새 유입

### Phase 2 — 해외 피벗 (진짜 시장)

**목적**: 언어 장벽 + 정보 비대칭 해소. 국내보다 AI 가치가 훨씬 높음.

- **지역**: 동남아·일본 우선 → 전 세계
- **데이터**: OpenStreetMap (전 세계, 무료) + Google Places selective enrichment (top 20개 도시, ~$170 1회성)
- **차별화**: 챗봇이 언어 장벽 보조 (메뉴 해석, 교통 안내, 긴급 대안)
- **피벗 조건**: 국내 재사용률 검증 완료 + 모두의 창업 등 자금 확보

## 타겟 사용자

### 국내 핵심 타겟
- **처음 가는 소도시 여행자**: "경주 처음인데 아무것도 몰라" — 정보 과부하 해소
- **커플/친구 그룹**: 취향 다른 일행의 일정 조율 피로 해소
- **계획 귀찮은 직장인**: 루트 생성에 30분 이상 쓰기 싫은 사람

### 해외 핵심 타겟
- 한국인 해외 여행자 (동남아, 일본, 유럽)
- 언어 장벽으로 현지 정보 접근이 어려운 여행자

## 가격 전략

### 국내/해외 분리 (구조 확정, 금액 추후 결정)

| 패스 | 대상 | 금액 |
|------|------|------|
| 국내 당일 패스 (`domestic_day`) | 국내 당일치기 | 추후 확정 |
| 국내 여행 패스 (`domestic_3night`) | 국내 3박 4일 이하 | 추후 확정 |
| 해외 당일 패스 (`overseas_day`) | 해외 당일 | 추후 확정 (국내보다 높음) |
| 해외 여행 패스 (`overseas_4night`) | 해외 4박 5일 이하 | 추후 확정 (국내보다 높음) |

**분리 이유**: 해외는 Google Places API 등 데이터 비용이 높고, 언어 보조 챗봇 사용량도 높아 가격 차등이 필요함.

### 첫 여행 무료 (획득 전략)
- 신규 가입 후 첫 여행은 전 기능 무료 사용 → 재사용률 확보 후 전환

## 국내 MVP 성공 기준

| 지표 | 목표 |
|------|------|
| D7 재사용률 | 30% 이상 |
| 트립 패스 전환율 | 10% 이상 |
| 루트 완성률 | 80% 이상 (생성 시작 → 저장 완료) |
| 루트 공유 비율 | 20% 이상 (바이럴 루프 검증) |

MAU 숫자보다 위 4가지가 해외 피벗 판단 기준.

## 연기된 기능

### Hidden Gems — 모두의 창업 지원금 이후

- **연기 이유**: 1차 지원금 미확보 → GPS 인증 기반 커뮤니티 구축 비용 부담
- **DB 구조는 유지**: `places.rarity_score`, `places.is_hidden_gem`, `hidden_gems` 테이블 유지, 로직만 비활성화
- **해외에서 더 중요**: 언어 장벽 + 정보 비대칭 → 해외 피벗 시 우선 적용
- **임시 대안**: `includeHiddenGems` → "얼마나 자주 가세요?" (방문 빈도 질문)으로 UX 대체

## 데이터 전략 요약

| 소스 | 역할 | 비용 |
|------|------|------|
| TourAPI | 국내 관광지·맛집·문화시설 배치 적재 | 무료 |
| 카카오 로컬 API | 국내 맛집·카페 배치 적재 + 카테고리 쿼터 미달 시 실시간 보충 | 무료 (월 300,000 트랜잭션) |
| 네이버 블로그 검색 | 핫플 trend_score 주 1회 갱신 | 무료 (일 25,000콜) |
| OpenWeatherMap | 날씨 기반 실외/실내 가중치 조정 | 무료 티어 |
| Google Maps Distance Matrix | OR-Tools TSP 실제 이동 시간 계산 | 유료 (MAU 1만 기준 $100~200/월) |
| OpenStreetMap | 해외 장소 베이스 (Phase 2) | 무료 |
| Google Places | 해외 top 20개 도시 selective 보강 (Phase 2) | ~$170 1회성 + ~$50~100/월 |
