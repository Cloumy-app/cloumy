# 기능 우선순위

> ⚠️ **2026-07-06 타겟 전환 반영**: 한국인 국내 여행자 → 방한 외국인 관광객(미국·일본·중국·대만). 아래 KPI·우선순위는 Notion "6. 로드맵 & KPI" 기준으로 갱신함. 상세 배경은 `planning/strategy.md` 참고.

## KPI 목표 (North Star: 여행 기간 중 루트를 실제로 사용해 완료한 Trip Pass 유저 수)

| 단계 | MAU | 루트 생성(누적) | Trip Pass 전환율 | MRR | 비고 |
|------|-----|-----------|-----------|------------|---------|
| Phase 1 (6개월) | 3,000명 | 10,000개 | ≥ 3% | $3,000+ | 여행기간 내 DAU율 ≥60%, 챗봇 사용률 ≥40% |
| Phase 2 (18개월) | 20,000명 | - | ≥ 5% | $15,000+ | LTV:CAC ≥3:1, 도시 커버리지 20개 |
| Phase 3 (36개월) | 100,000명 | - | - | $100,000+ | B2B 계약 10개 이상 |

## P0 — 반드시 (MVP 출시 조건)

이것 없으면 출시 자체가 불가능하거나 앱의 핵심 가치가 없다.

| 기능 | 난이도 | 개발 기간 | 비고 |
|------|--------|-----------|------|
| 소셜 로그인 (구글·애플 우선) | ★★ | 1~2주 | 애플은 앱스토어 필수. 카카오는 국내 전용 서비스라 외국인 타겟과 안 맞아 보류 (재검토 필요) |
| JWT 인증 시스템 | ★★ | 1주 | |
| **AI 루트 생성 + 지도 시각화** | ★★★★★ | 8~10주 | 앱 핵심 가치. 현재 14개 도시 구현됨(`ai/app/config/city_centers.py`), Notion MVP 목표 5개 도시는 이미 초과 달성 |
| **슬롯 대안 추천 (🔄)** | ★★★ | 3~4주 | 루트 생성 연장선 — 슬롯 단위 대안 3개 추천, 전체 재생성 X |
| **AI 챗봇 (여행 전·중)** | ★★★★ | 8~10주 | 핵심 차별화 |
| **예산 관리 & 지출 추적** | ★★★ | 4~5주 | 전 페르소나 공통 니즈 |
| 지도 내비 3-way 분기 (Naver/Google/카카오T) | ★★ | 1~2주 | 지하철·버스→Naver, 도보→Google, 택시→카카오T 딥링크 분기 — 계획, 미구현 |
| 트립 패스 결제 (PG 미확정) | ★★★ | 2~3주 | 토스페이먼츠는 국내 전용 PG — 외국인 카드 결제 미지원. Stripe 등 국제결제 검토 필요 (별도 논의) |
| 장소 데이터 파이프라인 | ★★★ | 2~3주 | TourAPI + 카카오 로컬 + **KOPIS** |
| pgvector 임베딩 파이프라인 | ★★★ | 1~2주 | RAG 기반 |

## P1 — 초기 출시 후 빠르게 추가

MVP 이후 리텐션과 성장에 직결되는 기능.

| 기능 | 난이도 | 개발 기간 | 비고 |
|------|--------|-----------|------|
| **Hidden Gems + 태그 커뮤니티** | ★★★ | 5~6주 | ⚠️ 자금 확보 후 구현 (모두의 창업 지원금 이후 — 현재 연기). 베타 헌터 300명, 시드 500~1,000개 사전 확보 필수 |
| **트렌딩 장소 수집 파이프라인** | ★★ | 2~3주 | 네이버 블로그 검색 API + 유튜브 Data API, Haiku로 장소명 추출, 주 1~2회 배치. trend_score를 RAG 가중치로 반영 |
| **그룹 여행 모드** | ★★★★ | 6~8주 | 개인 지출 추적 검증 후 추가 |
| **오프라인 저장** | ★★★ | 2~3주 | Phase 2 예정 → Phase 1 후반으로 당김 (Extended 패스 전용) |
| **콘서트·이벤트 앵커 (Serper API + KOPIS)** | ★★★ | 2~3주 | K-pop 콘서트 투어리스트 페르소나 핵심. Serper 실시간 검색+pgvector 캐시(TTL 7일), 클래식·뮤지컬은 KOPIS 우선 — 계획, 미구현 |
| **Foreigner Friendly Score** | ★★★ | 3~4주 | 영어메뉴/카드결제/영어키오스크/맵기 정보/식이 정보 5항목. 서울·부산 주요 200곳 수동 입력으로 시작 — 계획, 미구현. `places` 테이블에 관련 컬럼 자체가 없어 스키마 설계 선행 필요 |
| **취향 태그 시스템 재설계 (10종)** | ★★ | 2~3주 | 현재 `#관광`·`#야경` 등 한국어 해시태그 방식을 K-pop Pilgrim·K-food Lover 등 Notion 10종 영어 태그 체계로 전환 — 계획, 미구현 |
| **카메라 챗봇 (메뉴판·키오스크·간판 번역)** | ★★★★ | 4~5주 | KOIN K-amera 벤치마킹, 텍스트 챗봇에 카메라 입력 통합 — 계획, 미구현 |
| **다국어 UI 전면화 (일본어·중국어)** | ★★★ | 3~4주 | 챗봇은 이미 다국어 응답 지원(2026-07-06 완료), 로그인·온보딩·루트생성 등 나머지 화면 UI는 미마이그레이션 |
| FCM 푸시 알림 | ★★ | 1~2주 | 예산 초과, 핫플 경보 |
| 여행 후 지출 리포트 | ★★ | 1~2주 | Victory Native 차트 (2026-07-06 완료) |
| Elasticsearch 전문 검색 | ★★★ | 2~3주 | MAU 증가 후 전환 |
| 타임라인 알림 | ★★ | 1주 | 편의 기능 |

## P2 — 나중에 (Phase 2~3)

전략적 타이밍이 중요하거나 선행 조건이 필요한 기능.

| 기능 | 선행 조건 | 단계 |
|------|-----------|------|
| 투어·숙박 예약 연동 (Klook·Viator) | 파트너십 협상 (셀프서비스 API 아닌 제휴 계약 구조) | Phase 2 |
| AI 여행 일지 자동 생성 + SNS 공유 | 여행 전·중 기능 검증 | Phase 2 |
| 더치페이 정산 | 그룹 모드 안정화 | Phase 2 |
| 인앱 지도 내비 완전 구현 | UX 안정화 후 (MVP는 딥링크로 충분) | Phase 2 |
| 장소 데이터 다국어화 (`places.name`/`address` → 영/일/중간체/중번체, 방식 결정 완료 2026-07-10) | 스키마 마이그레이션 + 배치 번역 스크립트 구현 | Phase 1 후반~2 |
| 행동 기반 태그 자동 보정 | 이벤트 로깅 데이터 3개월 이상 축적 | Phase 2 |
| 이미지 기반 Vibe Search | AI 이미지 임베딩 파이프라인 별도 필요 | Phase 2 |
| 크리에이터 수익 분배 | 커뮤니티 활성화 후 | Phase 2~3 |
| 포인트 & 리워드 | 커뮤니티 활성화 후 | Phase 2 |
| 상표 출원 ("Cloumy") | - | Phase 2 시작 전 |
| B2B 대시보드 (관광청·지자체) | 유저 집계 데이터 확보 후 | Phase 3 |
| 실시간 동행 매칭 | 안전 정책 수립 후 | Phase 3 |
| 음성 챗봇 (STT) | STT 품질 검증 | Phase 3 |
| AR 포토스팟 | 기술 성숙도 검증 | Phase 3 |

> ⚠️ 기존에 있던 "해외 예약 연동(Kiwi.com·Trivago)", "해외 장소 DB(Foursquare/TripAdvisor)", "Amadeus Travel API", "Stripe 해외 결제"는 **한국인이 해외로 나가는(아웃바운드) 시나리오** 전제였던 항목 — 이번 타겟 전환(외국인이 한국에 오는 인바운드)과 맞지 않아 제거. 국제결제(Stripe 등) 자체는 P0 표의 "트립 패스 결제(PG 미확정)" 항목으로 이미 반영됨. 챗봇 다국어 번역은 2026-07-06 완료되어 항목에서 제거.
